# Wild Awakening (Android)
Game source: www/index.html (Three.js is included offline as www/three.min.js).
Build the APK: upload this whole folder (including the hidden .github folder) to a new GitHub repository,
open the Actions tab -> "Build APK" -> Run workflow, then download "WildAwakening-apk" when it finishes.
Install app-debug.apk on your phone (allow "install unknown apps").
